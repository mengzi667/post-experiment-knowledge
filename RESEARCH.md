# Workflow research: public summary

The implementation was grounded in privately accessible historical experiment reports, raw audit artifacts, read-only tracking metadata and existing synchronization scripts. Identifiers, exact experimental results, internal links and private analysis are intentionally excluded from this public-ready tree.

## Diagnosis

Two recurring structures create reading problems: complete data appended as very large same-document annexes, and result sections organized as a growing execution timeline. Exact-text deduplication alone does not reconstruct the current scientific understanding. Tracking state may differ from business-phase state, and historical health evidence may cease to describe current availability.

## Solution

Keep three linked views: a question-centered main report, an experiment/evidence index, and a lossless private archive. Preserve mixed facts and limitations before synthesizing them. Let new evidence update claims and decisions instead of adding another full report. Keep unavailable or contradictory sources explicit.

## Private study deliverables

Real-source snapshots, block inventories, source-to-destination mappings, curated main previews, evidence indexes and the detailed research report are outside the source tree. These are drafts for user review, not unauthorized production migrations. Coverage checks establish retention; a human must still judge whether the rewritten report is understandable in a few minutes.
