# Roadmap and current limits

v0.1: explicit-source archival; structured metadata; scoped comparison; evidence-checked Agent drafts and knowledge history; question-centered Markdown; historical XML inventories/previews; optional read-only MLflow; conservative Feishu atomic replacements; private journals; allowlisted packaging.

v0.2: template-first workflow, explicit topic selection and frozen template versions, structured report sections with flexible result blocks, stale-template sync protection, Windows UTF-8 CLI output. No automatic remote-template interpretation or background template update.

v0.3: introduction and plain-text hierarchy before native selection cards; joint template/save-method/archive-scope onboarding; local Markdown, Feishu or both; versioned destinations and target guards; trace/full private ZIP uploads with folder/hash readback, idempotency and unknown-result recovery; local plugin marketplace distribution. No document/folder creation, implicit raw upload, public listing requirement or new MCP service.

v0.4: distinct Wiki archival targets with node-parent/hash verification, verified adoption of relocated files without re-upload, and explicitly confirmed user-private personal-space defaults. Existing Drive archive plans remain valid as historical location evidence. User-specific Wiki links are not shipped in the package.

v0.5: Windows x64 release and standalone Skill can include official CPython 3.14.10, fixed archive/member hashes and licenses. A fixed-path isolated launcher removes the system-Python/pip requirement on that platform. Source-only builds remain available; macOS/Linux bundled interpreters are not provided. Feishu still needs each user's lark-cli and authorization.

0.5.0-beta.1 additionally includes a manifest-verified offline one-click installer, required concrete output-location onboarding, and context-aware credential checks for dynamic code/masked test values while retaining conservative blocks on unknown literals and compressed evidence. This is a Beta, not a stable release; see BETA.md.

Next, after demonstrated need: additional result profiles, richer Agent-reviewed historical mappings, native table-cell edits and separately approved insert/archive migrations, additional report platforms, stronger cross-process recovery tests and Linux-host execution validation.

Not planned: training design/execution, experiment scheduling, GPU management, automatic retries, background training monitors or automatic model-provider calls.

Formal document migration, live platform write fault injection, external binary-resource archiving, human readability sign-off and further client/platform validation remain separate. Project licensing is MIT; a release is described as publicly published only after its GitHub repository and assets are verified remotely.
